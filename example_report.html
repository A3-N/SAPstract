Scoring modelHow section and aggregate scores work

Each unique affected asset contributes Critical 30, High 18, Medium 8, or Low 3 points. Each section is capped independently at 100; the backward-compatible aggregate index is also capped at 100. Grade A is 0–9, B 10–24, C 25–49, D 50–74, and F 75–100. A score is a prioritization aid, not a probability of compromise. Duplicate evidence for the same rule and asset is de-duplicated.

Assessment boundaryWhat this host-local pass cannot prove

This host-local pass can prove file metadata, selected profile values, running processes/services, and local socket state at collection time. It cannot prove firewall reachability from another zone, SAP authorization design, current Security Notes, TLS cipher quality, SNC use on each session, database role design, ABAP code security, or whether an observed version is vulnerable. Those require authenticated and change-controlled follow-up.
